# 术语表（中英对照）

本项目**代码里的标识符、函数名、变量名一律保持英文**，只有注释与文档字符串使用中文。
这样做的原因有两个：

1. 你查资料时看到的论文、PyTorch 官方示例、开源实现都用这些英文词，对照着读不用二次翻译；
2. 术语在社区里有公认写法，硬翻成中文反而不容易搜到资料。

这份表用来把源码里的英文标识符和中文概念对应起来。
按「代码里出现的写法」字母顺序排列。

## 数据与切分

| 代码中的写法 | 中文含义 | 说明 |
|---|---|---|
| `RawRating` | 原始评分 | `ratings.dat` 里的一行，含原始用户/物品 ID 与评分 |
| `Interaction` | 正向交互 | 过滤掉低分后的一条记录，代表「用户喜欢过该物品」 |
| `positive_threshold` | 正反馈阈值 | 评分 `>= 4` 记为喜欢，本项目不区分 4 分和 5 分 |
| `IdMappings` | ID 映射表 | 原始 ID 与内部连续索引的双向映射 |
| `user_idx` / `item_idx` | 用户/物品索引 | 编码后的内部索引，从 0 开始，用于查 embedding |
| `original_user_id` / `original_item_id` | 原始用户/物品 ID | MovieLens 自带的稀疏 ID |
| `split` | 数据切分 | `train` / `validation` / `test` 三者之一 |
| `SPLIT_STRATEGY` | 切分策略 | 固定为每个用户留最后两条做验证与测试 |
| `PreparedData` | 预处理结果 | 三个切分 + ID 映射的集合 |

## 模型

| 代码中的写法 | 中文含义 | 说明 |
|---|---|---|
| `embedding` / `embedding_dim` | 嵌入 / 嵌入维度 | 把离散 ID 变成稠密向量的查表 |
| `Tower` | 塔 | Two-Tower 中的一侧网络（用户塔或物品塔） |
| `hidden_dim` / `output_dim` | 隐藏层维度 / 输出维度 | MLP 中间层宽度 / 最终向量宽度 |
| `tower_type` | 塔的类型 | `embedding` 表示直接查表，`mlp` 表示再过两层 MLP |
| `TwoTowerModel` | 双塔模型 | 用户与物品各一个塔，输出共享同一向量空间 |
| `MatrixFactorization` | 矩阵分解 | 最经典的隐向量点积模型 |
| `SASRec` | 自注意力序列推荐 | 用因果自注意力预测下一个物品 |
| `causal_mask` | 因果掩码 | 挡住未来位置，保证「只能看历史」 |
| `padding_mask` | 补齐掩码 | 标出补齐位置，避免它们参与计算 |
| `max_seq_len` | 最大序列长度 | 序列截断/补齐后的固定长度 |

## 训练与损失

| 代码中的写法 | 中文含义 | 说明 |
|---|---|---|
| `logits` | 未归一化分数 | 送进 softmax / sigmoid 之前的原始分数 |
| `similarity_matrix` | 相似度矩阵 | 用户向量与物品向量两两内积的结果 |
| `temperature` | 温度系数 | 相似度除以它再进 softmax，越小越尖锐 |
| `in_batch_negatives` | 批内负采样 | 同批次里其他人的正样本，天然当作本用户的负样本 |
| `in_batch_cross_entropy_loss` | 批内交叉熵损失 | 对角为正样本、每行做一次多分类 |
| `false_negative_mask` | 假负样本掩码 | 标出「其实也是正样本」的位置，避免被当负样本惩罚 |
| `negative sampling` | 负采样 | 随机抽未交互物品作为负样本 |
| `epoch` | 训练轮次 | 完整遍历训练集一次 |
| `patience` | 早停耐心值 | 验证集连续多少轮无提升就停止 |
| `early stopping` | 早停 | 验证指标不再改善时提前结束训练 |
| `checkpoint` | 模型存档 | 保存权重与配置的文件 |
| `best_epoch` | 最佳轮次 | 验证集指标最好的一轮，用于选择存档 |
| `optimizer` / `learning_rate` | 优化器 / 学习率 | 本项目统一用 Adam |

## 召回与排序

| 代码中的写法 | 中文含义 | 说明 |
|---|---|---|
| `retrieval` | 召回 | 从全量物品中快速筛出候选 |
| `ranking` | 排序 | 给候选打分并排出顺序 |
| `brute_force` | 暴力检索 | 直接用矩阵乘法算全部分数，结果精确 |
| `FAISS` / `IndexFlatIP` | 向量检索库 / 精确内积索引 | 穷举式精确检索，**不是**近似最近邻 |
| `top_k` | 前 K 个 | 分数最高的 K 个物品 |
| `seen_items` | 已看物品 | 训练集中已交互过、必须从推荐里过滤掉的物品 |
| `filter` / `mask` | 过滤 / 屏蔽 | 把不可推荐的位置分数压到 `-inf` |
| `candidate` | 候选项 | 参与排序的物品集合 |
| `L2 normalize` | L2 归一化 | 把向量长度变成 1，使内积等于余弦相似度 |
| `inner product` | 内积 | 两个向量逐元素相乘再求和 |

## 评测指标

| 代码中的写法 | 中文含义 | 说明 |
|---|---|---|
| `ground_truth` | 标准答案 | 每个用户真正相关的物品集合 |
| `Recall@K` | 召回率@K | 前 K 个推荐里命中相关物品的比例 |
| `HitRate@K` | 命中率@K | 前 K 个里至少命中一个的用户占比 |
| `NDCG@K` | 归一化折损累计增益@K | 命中物品排得越靠前，得分越高 |
| `DCG` / `IDCG` | 折损累计增益 / 理想值 | NDCG 的分子与分母 |
| `leave-one-out` | 留一法 | 每个用户只留一个物品做测试 |
| `full-ranking` | 全量排序 | 在全部物品上排序，而不是只对采样候选排序 |
| `seen-item filtering` | 已看物品过滤 | 评测前先剔除训练集交互，避免刷分 |
| `evaluation protocol` | 评测协议 | 切分方式、历史长度、过滤规则的统称 |
| `data leakage` | 数据泄漏 | 评测时用到了模型本不该看到的信息 |

## 常用操作

| 代码中的写法 | 中文含义 | 说明 |
|---|---|---|
| `forward` | 前向传播 | `nn.Module` 的标准入口方法 |
| `encode_users` / `encode_items` | 编码用户/物品 | 本项目所有可召回模型都提供这两个方法 |
| `state_dict` | 参数状态字典 | PyTorch 保存/加载权重的格式 |
| `DataLoader` | 数据加载器 | 负责分批与打乱 |
| `generator` | 随机数生成器 | 固定种子后，打乱顺序与采样可复现 |
| `seed` | 随机种子 | 控制可复现性 |
| `device` | 计算设备 | `cpu` 或 `cuda`；`auto` 表示自动选择 |
| `no_grad` | 关闭梯度 | 评测/推理时省内存并加速 |
| `deepcopy` | 深拷贝 | 保存当前权重快照，避免被后续训练覆盖 |
