# 02｜一条序列怎么变成一堆标签

第 01 篇确定了用序列、不用静态画像。这一篇解决"怎么把一条用户历史变成能训练的东西"——错位对齐、补齐方向、负样本从哪来、loss 在哪些位置上算。这几步每一步都能写错，而且**都不会报错**。

## 一、错位一格

对长度为 6 的序列 `[a, b, c, d, e, f]`：

```text
输入   a  b  c  d  e
目标   b  c  d  e  f
```

位置 `t` 的隐状态预测位置 `t` 的目标。这一格错位的方向只有一个正确答案：**目标整体后移一位**，不是前移。

写反了会发生什么？输入变成 `[b, c, d, e, f]`、目标 `[a, b, c, d, e]`，也就是"用未来预测过去"。因为 MovieLens 的交互序列本身有时间自相关（同一个用户相邻的行为往往类型相近），模型仍然能学到东西，loss 照降、指标也不至于崩到随机水平——所以这个 bug 靠看指标是发现不了的。它只会让你的离线结果比真实能力乐观一点点，然后在真正部署时露馅。

一个能验证对齐方向的检查，不用跑训练：

```text
输入序列的最后一位  ==  该用户倒数第二个物品（token 化之后）
正样本的最后一位    ==  该用户最后一个物品
```

两个都成立，错位方向才是对的。`labs/lab5` 的 `✅ 跑一下` 里就有这条断言。

## 二、只取最近 L+1 个，并且只能往右补

历史很长的用户要截断。下面是 MovieLens 历史协议的长度分布；原始探针产物未随仓库保存，不能作为新协议统计使用：

```text
序列长度 中位数 / 均值 / 最长: 56 / 93.3 / 1433
长度超过 50 的用户: 5,447 / 6,038  (90.2%)
长度不超过 10 的用户: 1,229
```

取最近 50 个是个取舍：截掉的部分对"下一个买什么"信息量低，而注意力对 `L` 是平方开销。代价是九成用户会被砍掉一点——在 MovieLens 这种长期评分数据上这是有损的；换成短会话数据（一次会话 5~20 次点击），截断几乎无损。

截断之后要补齐成定长。**补齐只能加在右边**，这不是风格问题：序列的表示取"最后一个非补齐位置"的隐状态（第 03 篇会用这条），左补齐时那个位置正好是补齐位，取出来是全零向量。它不报错，只是让所有短历史用户得到一个没有信息的表示。

还有一件容易漏的事：token `0` 留给了补齐位，所以 `item_idx = i` 的物品必须用 token `i + 1` 表示。**这个 +1 只能加一次。** 输入序列、正样本序列、负样本序列最后都要落在同一个 token 空间里：

| | 谁负责加 1 |
|---|---|
| `input_sequence` | `pad_item_sequence`（切片之后整体 +1） |
| `positive_sequence` | 同一个函数（切的是 `items[1:]`） |
| `negative_sequence` | `sample_negative_item` 的返回值**已经是 token**，直接补 0 |

漏加会让编号整体错位一格、多加会让它错位两格，两者都不报错。这是这一章最容易出的一类错，也是源码 `src/recsys/training/samplers.py` 特意把 `+1` 收进采样函数里的原因——约定只有一处。

## 三、负样本：每个位置配一个"他确实没看过"的

上一步切出来的表里只有正样本。模型被告知"这个位置的答案是 `d`"，但没被告知"不是 `x`"。只做正样本的二分类，把所有物品的分数一起推高就够了。

所以每个位置再配一个负样本。这里有一处和 Two-Tower 的**结构差异**值得说清：

| | Two-Tower | SASRec |
|---|---|---|
| 负样本来自哪 | 同一个 batch 里**其他用户**的正样本 | 随机抽一个**该用户没交互过**的物品 |
| 每个正样本配几个 | 最多 B-1 个（单向 in-batch；mask 后更少） | 1 个 |
| 有没有假负样本问题 | 有（第 04 篇量化过 21.1%） | 没有，但要显式排除该用户自己的正样本 |

Two-Tower 的假负样本问题是"别人的正样本被我当成了负样本"，**它出在训练 batch 的非对角位置，和评估候选集无关**。SASRec 这里不存在这个问题：负样本是抽出来的，除了该用户自己的历史，不来自任何人。代价是每个位置的负样本只有 1 个，训练信号比 in-batch 弱得多——第 04 篇会看到这直接体现在收敛速度上。

### 拒绝采样有多"随便"

抽取方式是拒绝采样：随机挑一个，如果恰好是这个用户交互过的就重抽。它在什么样的规模下才不会卡？实测扫过一整个训练集的 231,522 个位置：

```text
候选位置数                    231,522
第一次抽就撞上已看物品的比例   3.25%
平均每个位置抽几次            1.035
一个位置最多抽过几次          7
```

读法：**撞上的概率在百分之三的量级**，所以拒绝采样几乎不空转（平均多抽 0.035 次）；7 次那个是长尾，不影响总体。

这个数是"用户平均 93 次交互、物品池 3533 个"撑出来的。换成物品池只有几百个、或者用户极其活跃的场景，第一次就撞上的概率会成倍上升，重抽次数没有上界保证——那时候要换成按物品权重采样，或者干脆维护一份"未交互候选集"。

### 一个必须守住的边界

用于排除的 `seen_items` **只能来自训练集**。

如果把它换成"训练集 + validation + test"，负样本就会系统性地避开这些物品，等于在训练阶段告诉模型"这些物品是特殊的"。而评测要预测的正是这些物品，指标会虚高，且没有任何异常现象可供察觉。这和第 01 篇的时间切分是同一件事的两面：**训练阶段能看到的信息，只能是目标时刻之前的信息。**

## 四、loss 在哪些位置上算

每个位置有两条监督，都是二分类交叉熵（输入是 logit）：

```text
L = (1/N) · Σ_t [ BCE( s_t⁺ , 1 ) + BCE( s_t⁻ , 0 ) ]

s_t⁺ = h_t · e_{positive_t}
s_t⁻ = h_t · e_{negative_t}
```

`N` 是**有效位置数**，不是 `B × L`。补齐位置的 `positive_sequence` 是 0，如果照算不误，模型会被要求"让第 7 个位置的分数匹配一个不存在的物品"，梯度方向完全是噪声。

做法是用正样本序列的 `!= 0` 当掩码：

```text
valid = positive_sequence != 0        # [B, L]
loss  = BCE(positive_logits[valid], 1) + BCE(negative_logits[valid], 0)
```

**掩码只做一次，两张 logits 共用。** 因为 `positive_sequence` 和 `negative_sequence` 是逐位置对齐的：第 `t` 个位置有效，两张表在 `t` 上都有效；第 `t` 个位置是补齐位，两张在 `t` 上都是 0。分别算两个掩码是把简单问题复杂化，而且一旦两边的补齐长度不一致（比如负样本忘了补），共用掩码会直接把它暴露出来。

这个结构和第 04 篇那个 false negative mask 是同一类手法：**先确定哪些位置该参与，再算 loss。** 区别是那次掩掉的是"不该当负类的候选"，这次掩掉的是"根本不存在的目标"。

顺手记一个会用到的数字：随机初始化、分数接近 0 时，正负两个 BCE 各是 `ln 2`，所以初始 loss 在 `2 ln 2 = 1.3863` 附近。它是训练曲线的锚点——第一轮的 loss 如果没有落在 1.35~1.40，多半是**有效位置数**或者**维度对齐**出了问题。

## 这一篇的坑

1. **错位方向写反**（用未来预测过去）。指标不会崩，只会乐观一点点。
2. **`+1` 加了两遍或者漏加**，编号整体错位，训练照样收敛。
3. **左补齐**，短历史用户的序列表示变成零向量。
4. **`seen_items` 混进 validation/test**，负样本避开评测目标，指标虚高。
5. **loss 除以 `B × L` 而不是有效位置数**，等于给短序列更大的权重。

## 文献

- **SASRec**：Kang & McAuley, *Self-Attentive Sequential Recommendation*, ICDM 2018（[arXiv](https://arxiv.org/abs/1808.09781)）——逐位置"预测下一个物品"的目标设定出自这篇；论文的 3.2 节也讨论了每个位置配一个负样本的做法和它的局限。
- **GRU4Rec**：Hidasi et al., *Session-based Recommendations with Recurrent Neural Networks*, ICLR 2016（[arXiv](https://arxiv.org/abs/1511.06939)）——较早系统使用"每步一个负样本 + 排序损失"的工作，可以对照看负样本数量对收敛的影响。
- **NCE**：Gutmann & Hyvärinen, *Noise-Contrastive Estimation: A New Estimation Principle for Unnormalized Statistical Models*, AISTATS 2010（[JMLR](https://proceedings.mlr.press/v9/gutmann10a.html)）——把"从全部候选中挑出正样本"近似成二分类的理论来源；采样多少负样本、怎么采，本质上是在估计这个近似的方差。
